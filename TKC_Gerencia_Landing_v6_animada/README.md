# Mini landing de Gerencia - TKC Fumigaciones Group

Archivos incluidos:
- `index.html`: estructura principal.
- `styles.css`: visual responsive con paleta TKC.
- `script.js`: enlace de WhatsApp con mensaje prellenado.
- `yesenia-morales-mora.vcf`: contacto descargable.
- `assets/tkc-logo-white.png`: logo blanco para el hero.
- `assets/tkc-logo-color.png`: logo en color para usos futuros.

## Publicación dentro del dominio

Subir esta carpeta a una ruta equivalente a:

`https://fumigacionestkc.com/gerencia/`

El servidor debe resolver `index.html` como documento inicial.
